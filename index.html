BSA droplet morphology labelling

You'll see one microscope image of a droplet at a time and choose which of seven categories it belongs to (plus unsure / don't include). The aim is at least 400 droplets in each category. It goes quickly once you get going: press 1–8 and it advances by itself.

You can stop and come back whenever you like. Nothing is ever lost, and anything you've already filed can be moved to a different category later from the Review tab.

The categories

Get started

  1. Type your name below.
  2. Click Choose save file and save a file called bsa-droplet-labels.json somewhere you'll find it again, like your Desktop.
  3. Label away. Every single answer is written into that file the moment you make it — there is no save button and nothing to remember.
  4. When you're done (or want to send progress), email that file back.
This browser can't save straight to a file. Your work will be kept inside this browser instead, which is usually fine but can be wiped if you clear your browsing data. Please use Google Chrome for this task if you can. If you carry on here, use the Backup button regularly.

Restore from a file

Changed computer, or something went wrong? Open a bsa-droplet-labels.json you saved earlier and carry on from exactly where it stopped.

Which is it? — press 1–8

Click tiles to select them (shift-click for a range), then press 1–8 or use the bar at the bottom to move them somewhere else.

Guide

One droplet per image. Label what you can actually see, not what you think it ought to be. If two categories both seem right, pick the closer one and move on — you can revisit it from Review later. If you genuinely can't tell, use Unsure / don't include.
